A heading is the whole set. Tick it and the set is installed as a set — recorded, and offered an update when the channel publishes a newer version. It follows the rules under it: tick every one of them and the heading ticks itself, untick a single one and it lets go, because a set with a rule missing from it is not the set. Open a heading and tick rules individually to take only those: single rules are copies, and nothing will ever correct them.
Nothing is selected to begin with, so a policy is whatever you choose to put in it. Basic sets ticks the eight that assume nothing about the application behind the proxy, which is the usual starting point.
An optional set only matters in front of the application it names — one for a stack you do not run cannot detect anything, and can only match something legitimate.
