    {# ── 3: HTTPS ────────────────────────────────────────────── #} {% elif step == 3 %}
    Step 3 of 6 — Turn on HTTPS
    {% if done.https %}

    {{ site.name }} serves HTTPS on port {{ site.https_port }}.

    Plain HTTP still works beside it. When you have seen https://{{ site.server_name }}/ work, tick Redirect HTTP to HTTPS on the site's page.

    {% else %}

    One press gets {{ site.server_name }} a certificate from Let's Encrypt and serves it on port {{ site.https_port | default(value=443) }}. EasyWAF answers the validation itself; nothing changes on your application, and the certificate renews by itself.

    This works only once {{ site.server_name }} resolves to this host from the internet and port 80 is open to it — which is why step 2 came first.
    {% if is_admin | default(value=false) %}
    This can take up to a minute.

    Have a certificate already? Upload it in the Certificate Manager and choose it on the site's page.

    Step 6 of 6 — What happens next

    {% if done.policy and site.mode == "DetectionOnly" %} {{ site.name }} is being watched, and nothing is being refused yet. The rest takes days rather than minutes, and it is yours to do: {% elif done.policy and site.mode == "On" %} {{ site.name }} is protected: its policy is enforcing. What is left is keeping it right: {% else %} The setup is not finished — step 4 puts a policy on the site. Once one is watching: {% endif %}

    1. Leave it a few days, long enough to see whatever your site does weekly.
    2. Read what it would have blocked in Traffic Monitor. Each row is an attack, which you want refused, or your own traffic tripping a rule.
    3. Fix the false positives, narrowest first: exclude for this IP on the row, an exclusion for a path under Rule Exclusions, or the rule switched off on the policy. For a caller you trust, Allow on the row.
    4. Enforce. When the only rows that would have been blocked are ones you are happy to block, set the policy's mode to On{% if site.policy %} on its page{% endif %}. {% if site.mode == "On" %} done{% endif %}
