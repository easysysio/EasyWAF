Every port listed serves this site: same upstream, same policy, same certificate. Routing is by Host: and never looked at the port, so they behave identically.

HTTPS

Leave the port empty to serve this site over plain HTTP only. Setting it serves HTTPS as well as HTTP — the two are independent, so enabling one never switches the other off. Certificates are chosen per site by SNI, so many sites can share one HTTPS port.

Each presents this site's certificate. A site with an HTTPS port and no certificate cannot complete a handshake, so the port is not bound at all rather than bound and failing every connection.
The first port listed is the one an HTTP-to-HTTPS redirect sends visitors to, since a redirect has to name one.

A site with an HTTPS port but no certificate cannot complete a handshake, so its port is not bound at all rather than bound and failing. Upload certificates under Certificates.
