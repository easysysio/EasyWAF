Clickjacking is framing by another origin, which SAMEORIGIN already prevents. DENY also stops a site framing its own pages, which breaks applications that do — Nextcloud and Collabora among them, and Nextcloud reports the header as misconfigured when it sees it.

HTTPS

Leave the port empty to serve this site over plain HTTP only. Setting it serves HTTPS as well as HTTP — the two are independent, so enabling one never switches the other off. Certificates are chosen per site by SNI, so many sites can share one HTTPS port.

A site with an HTTPS port but no certificate cannot complete a handshake, so its port is not bound at all rather than bound and failing. Upload certificates under Certificates, or get one from Let's Encrypt below.

More ports answering this same site: same upstream, same policy, same certificate. Routing is by Host: and never looked at the port, so every one of these behaves exactly like the primary.
A port added here binds immediately. A port removed here stops being served but its listener stays bound until EasyWAF restarts — a bound socket cannot be given back mid-process.

Each presents this site's certificate. Like the primary HTTPS port, one listed here is not bound at all unless a certificate is selected — binding with nothing to present fails every handshake, which looks like a working configuration and is not.

Let's Encrypt

Requests a certificate for {{ site.server_name }} and assigns it to this site. EasyWAF answers the challenge itself, so there is nothing to configure on the backend.

For this to work, {{ site.server_name }} must resolve to this host from the public internet, and port 80 must be open to it. HTTP-01 validation always arrives there, and EasyWAF listens on port 80 whatever ports your sites use — so this site being on {{ site.listen_port }} does not matter. Set the contact address under Settings first, and start with the staging directory.
