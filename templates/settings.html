Traffic

EasyWAF records one row per proxied request. With retention off the table grows for as long as the proxy runs; setting a window deletes anything older, at startup and hourly after that. {{ stored_events }} events are stored right now.

Maintenance

Disabling a site under Sites stops EasyWAF proxying it. Visitors then get this message with a 503 Service Unavailable, rather than a 404 that reads as though the site is gone for good. Leave it empty for the default wording.

TLS

This is one setting for the whole appliance rather than per site: the TLS version and cipher suites are fixed when a listener binds its port, before the client has said which site it wants, so sites sharing a port necessarily share them. Certificates are per site — those are chosen by SNI during the handshake.
There is no weak-cipher option to pick: nothing below TLS 1.2, and no RC4, 3DES or CBC-SHA1, is implemented at all. Modern refuses clients that only speak TLS 1.2.
A change here takes effect when listeners are next bound, which means after a restart.

Edit the line down to the suites your policy permits. Names are checked on save — an unrecognised one is refused rather than quietly dropped, so a restriction you think is in force always is. Order is not yours to set: the server offers them strongest first.
Every suite here is AEAD. If a standard forbids CBC, or RC4, or 3DES, or static-RSA key exchange, that is already satisfied — none is implemented, so none can be selected. The TLS 1.2 suites are all ECDHE, so all have forward secrecy. TLS13_ suites apply to TLS 1.3 and the rest to TLS 1.2; leaving one family out under Compatible means clients of that version cannot connect.
